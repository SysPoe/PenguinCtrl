# CuSus release notes

This package contains the CuSus operator application and its supervisor. The
release version, source commit, build time, supported Windows versions, schema
versions, signing state, dependency inventory, and file hashes are recorded in
`release-manifest.json`, `SBOM.spdx.json`, and `SHA256SUMS.txt` beside these
notes.

Before using a release in a production, run the pre-show readiness checks with
the actual audio routes, displays, remote targets, timecode source, and warm
spare configuration for that venue.
